# Project Directive: B.Tech CSE Study Hub
## Overview
Build a comprehensive web application for B.Tech Computer Science Engineering students, teachers, and techies to access notes, project ideas, seminar topics, and study routines.
## User Roles
1. Student: Browse, download, track habits, upload notes.
2. Teacher/Professor: Upload verified notes, approve community contributions.
3. Techie: Contribute practical industry/project guides.
## Core Features
1. Multi-role Authentication (Supabase Auth).
2. Resource Dashboard: Search & filter by Semester (S1-S8), Subject, and Category (Free/Paid).
3. Upload & File Management: Upload PDFs/Docs with Supabase Storage.
4. Monetization: Integration for purchasing paid notes/courses.
5. Habit & Study Routine Tracker: Daily check-in streak and task checklist.
## Tech Stack
- Frontend: Next.js (App Router), React, Tailwind CSS, Lucide Icons.
- Backend/Database: Supabase (PostgreSQL, Auth, Storage).
